# Reference Intake

References are primary creative direction.

## Classify Each Reference

- rough sketch: composition and intent, not necessarily visual style
- storyboard panels: sequence spine; each panel becomes a shot row
- reference photo: subject anchor or style anchor; decide which
- existing generated frame: style/identity anchor; skip broad direction exploration if the user says to match it
- mood board: aggregate tone, not literal copy
- UI mockup/static graphic: animate the supplied design rather than redesigning it

## Visual Read

For each important visual reference, extract:

1. subject
2. composition
3. implied motion
4. palette/style signals
5. typography or labels
6. what must be preserved
7. what can be reinterpreted

## Arrows And Annotations

- Arrows on subjects are subject motion.
- Arrows around frame edges are camera or layer motion.
- Numbered panels are sequence order.
- Text labels should be quoted exactly before being turned into captions.

## Composition Preservation

Preserve subject placement, negative space, scale relationship, and eyeline unless the composition is technically broken for the requested aspect ratio.

If you change composition, say why.
